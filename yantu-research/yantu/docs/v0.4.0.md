# v0.4.0 实时协作

本版为研途原生文档（`.ytdoc`、内容模型 v2）加入正文多人实时编辑。同课题组成员获得文档的“可编辑”共享权限后，可同时打开文档；正文修改通过 WebSocket/Yjs 合并，其他窗口立即显示，在线人数显示去重后的账号数。只读共享仍可查看。文档标题、资源附件与文档引用暂由所有者管理。

## 使用与验收

1. 所有者在云盘中打开原生文档，确认页面显示“已同步到云端”。
2. 在“分享”中选择同课题组成员并设为“可编辑”。旧格式文档需先转换到内容模型 v2。
3. 两个账号各自打开同一文档，在不同位置输入，确认双方实时看到合并结果；刷新后再次确认内容。
4. 所有者将权限改为“只读”或撤销共享，当前编辑连接会关闭，后续写入被拒绝。

## 运行约束

- 协作房间保存在单个后端进程内。部署时先使用 **一个 Uvicorn worker**；多进程或多实例需要后续增加共享消息总线和跨实例房间协调。
- 持久化状态位于 `uploads/.collaboration/*.bin`；常规文档 JSON 版本是编辑后的投影。备份、迁移或验收复制时必须同时保留数据库、`uploads` 文件和该子目录。`run_acceptance.py` 已将其纳入快照与核验。
- 当前仅支持正文协作和在线人数，尚无其他成员的光标位置、协同标题编辑和资源插入权限。旧 Markdown、内容模型 v1 或与编辑器不兼容的文档仍按原有兼容路径处理。
